# FinanziApp

Sistema web de gestión financiera personal.

## Descripción

FinanziApp permite a los usuarios gestionar sus finanzas personales,
registrando ingresos y gastos, clasificando transacciones, creando
presupuestos y metas de ahorro, consultando reportes y recibiendo alertas.

## Tecnologías

### Frontend
- React
- TypeScript
- Vite

### Backend
- Java
- Spring Boot
- Spring Security
- JWT
- JPA / Hibernate

### Base de datos
- PostgreSQL
